# Chances
A FREE game based off of a slot machine, hit download on the files above!

How to download:

1. hit the code button above the files,

2. hit download ZIP,

3. unZIP the file so it can access other files,

4. hit "RUN GAME.html" to run the game,

5. Play and have fun!
